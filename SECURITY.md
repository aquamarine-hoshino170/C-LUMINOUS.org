# Security Policy

## Supported versions

We encourage users to keep up to date with the latest version of the project.
The maintainers will review security issues for the current main branch and the
latest published release when applicable.

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities.
Instead, report them privately to the maintainer through the repository's
security contact or by reaching out to the project owner directly.

If available, include:

- a description of the vulnerability
- affected files, components, or behavior
- reproduction steps or proof of concept
- your suggested fix or mitigation, if known

We appreciate responsible disclosure and will do our best to investigate and
respond in a timely manner.

## Disclosure expectations

We ask reporters to allow a reasonable period for the maintainers to investigate
and fix the issue before public disclosure.

If the issue is confirmed, a coordinated disclosure plan will be agreed with the
reporter when possible.
